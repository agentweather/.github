### Agent Weather: forecasts for the agent economy

We turn live AI-agent ecosystem signals into a weather-style, machine-readable report: framework activity, provider outages, MCP Registry churn, package adoption and payment-rail health. **AI agents buy it per call over x402: RLUSD on the XRP Ledger or USDC on Base.** No keys, no accounts, no signup.

**For agents**
- Paid endpoint: `GET https://api.agentweather.io/v1/agent-weather/current`, **0.007 RLUSD on XRPL (`xrpl:0`) or 0.007 USDC on Base (`eip155:8453`)** (x402 `exact`). Current prices for every route: [`/.well-known/x402`](https://api.agentweather.io/.well-known/x402)
- Discovery: [`/.well-known/x402`](https://api.agentweather.io/.well-known/x402) · [`llms.txt`](https://api.agentweather.io/llms.txt) · [OpenAPI](https://api.agentweather.io/openapi.json)
- Listed on the [XRPL AI Hub](https://xrpl-ai.org/directory)
