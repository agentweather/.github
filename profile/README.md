### Agent Weather: forecasts for the agent economy

We turn live AI-agent ecosystem signals into a weather-style, machine-readable report: framework activity, provider outages, MCP Registry churn, package adoption and payment-rail health. **AI agents buy it per call over x402 on the XRP Ledger.** No keys, no accounts, no signup.

**For agents**
- Paid endpoint: `GET https://api.agentweather.io/v1/agent-weather/current`, **0.01 XRP or 0.01 RLUSD** (x402 `exact`, `xrpl:0`)
- Discovery: [`/.well-known/x402`](https://api.agentweather.io/.well-known/x402) · [`llms.txt`](https://github.com/agentweather/agent-weather/blob/main/llms.txt) · [OpenAPI](https://github.com/agentweather/agent-weather/blob/main/openapi.yaml)
- Listed on the [XRPL AI Hub](https://xrpl-ai.org/directory)
